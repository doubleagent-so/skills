# Double Agent skills

Agent Skills for [Double Agent](https://doubleagent.so), which labels every website visitor as human, bot or AI agent.

```bash
npx skills add doubleagent-so/skills
```

Then ask your coding agent: *"Install Double Agent on this site."* It installs keyless by default (script only, no account).

- Skill: [`skills/doubleagent/SKILL.md`](skills/doubleagent/SKILL.md)
- Docs: https://doubleagent.so/install.md · CLI: `npx @doubleagent-so/cli init`

This repo is generated from the Double Agent monorepo. Please open issues here, but don't edit files directly.
